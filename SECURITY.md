# Política de segurança

Se encontrar uma vulnerabilidade neste kit, use **Report a vulnerability** na aba **Security** do [repositório no GitHub](https://github.com/lukasspires/github-copilot-fullstack-kit/security). Esse canal permite compartilhar detalhes de forma privada com o mantenedor.

Inclua uma descrição do impacto, passos mínimos para reproduzir, versões ou commits afetados e uma sugestão de correção, se houver. Não publique credenciais, dados pessoais, detalhes de exploração ou informações de ambientes internos em issues ou pull requests.

O mantenedor analisará o relato e combinará a divulgação após a correção. Não há prazo de resposta ou programa de recompensa garantido.
