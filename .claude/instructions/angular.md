# Angular instructions

- Detect installed Angular and TypeScript versions and follow existing component, state, forms, RxJS, UI-library, and test patterns.
- Keep components focused; place reusable data access and domain behavior in services or stores.
- Use strict types, narrow external `unknown` values, and prevent subscription leaks with the repository pattern.
- Avoid unsafe HTML and direct DOM manipulation unless reviewed.
- Cover accessibility, keyboard and focus behavior, responsive layout, and loading, empty, validation, error, and success states.
- Change dependencies or lockfiles only when required.
